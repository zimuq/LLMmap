## D — The question

> **Does CVaR-weighting the joint statistic (`γ < 1`) produce a
> measurably better `JointGreedy` selection — on worst-class or
> worst-tail metrics, at any `k` — than mean-weighting it (`γ = 1`),
> once evaluated through D009's exact trained-classifier protocol? Or
> does the joint (concatenated) statistic already implicitly
> prioritize hard pairs well enough that `γ` stops mattering for this
> algorithm, unlike it did for `GreedyCover` (D008)?**

This is `C1`'s ablation, never run for `JointGreedy`. D008 already
answered it for `GreedyCover`: lower `γ` cost nothing on mean accuracy
and helped worst-class at small `k`. Whether the same holds for
`JointGreedy` is not assumed — it could go either way, and either
answer is useful.

### A mechanism worth pre-registering, not just running the grid blind

**Hypothesis (stated before any new run, per this project's standing
practice):** `GreedyCover`'s MAX-aggregated coverage needs `γ<1` because
under mean/`γ=1`, easy pairs (separable by many queries) can dominate
the objective and crowd out hard ones. `JointGreedy`'s advantage (D010)
comes from set-level *interaction* — and interaction plausibly matters
*most* exactly on hard, near-relative pairs, where no single query is
strong but combinations are (D010/R6's `q=0` finding). If that's right,
**mean-aggregation might already implicitly favor hard pairs for the
joint statistic**, in a way it never did for the per-query one — making
`γ` less necessary for `JointGreedy`, not equally necessary. **If the
grid shows `γ` mattering just as much for `JointGreedy` as it did for
`GreedyCover`, this hypothesis is wrong and `R` must say so plainly**,
not quietly drop it.

### Why this exists now

Cheap, and it closes a genuinely open item (`C1`) for the algorithm the
project's evidence currently favors. D010 already built the
infrastructure (`LLMmap/joint_statistic.py`,
`LLMmap/joint_greedy.py`) and D009 already established the
trained-evaluation protocol — this D applies both to one new,
well-motivated axis of variation, `γ`, rather than opening new
infrastructure.

### What's already decided and does not block this D

- **`γ = 0.1` is already run — it's D010's own result.** Do not
  re-select or retrain that condition; reuse `results/D010/selection.json`
  and `results/D010/metrics_by_k.json` verbatim (I6). This D produces
  the other grid points only.
- **Grid: `γ ∈ {1.0, 0.25, 0.05}`**, matching `C1`'s original ablation
  set (`{1.0, 0.25, 0.1, 0.05}`) minus the already-run 0.1.
- **Training protocol fixed, reuse D009/D010's exactly** — same
  `hparams` hash, same `S_build`/`S_val`/`S_test` split (I2), same
  5-seed scheme. This D varies only which `γ` built each `k=1..8`
  chain.
- **Does not touch `GreedyCover` or I4's machinery** — `C1`'s
  `GreedyCover` ablation is already closed (D008); this D is
  `JointGreedy`-only.

## What counts as an answer

| Outcome | Criterion |
|---|---|
| **CONFIRMED (γ matters for JointGreedy too)** | Lower `γ` (0.05 or 0.25) shows a meaningfully better worst-class or worst-3 metric than `γ=1` at one or more `k`, mirroring D008's `GreedyCover` pattern. The pre-registered hypothesis above is wrong — state that plainly. |
| **NULL (γ doesn't matter for JointGreedy)** | All four `γ` values (`0.05, 0.1, 0.25, 1.0`) perform statistically indistinguishably across all four `METHOD.md §8` metrics, at every `k`. **Not a failure** — it would mean the joint statistic already captures what CVaR-weighting buys `GreedyCover`, and the pre-registered hypothesis is supported. Recommend `γ=1` (mean) as `JointGreedy`'s default going forward — simpler, no CVaR machinery needed. |
| **INCONCLUSIVE** | Mixed or noisy signal not attributable to a clear cause (e.g. the 5-seed range swallows every `γ`-to-`γ` delta at every `k` without a consistent sign, the same resolution wall D008/D009/D010/D011 have each hit before). Distinguish explicitly from NULL: NULL requires the values to look genuinely similar, not just noisy. |

**S6 — Report all four `METHOD.md §8` metrics, for all four `γ` values,

direct comparability across the two algorithms' γ-sensitivity.

**S7 — Write `## R`:** verdict, the pre-registered hypothesis's
disposition (confirmed or refuted, stated plainly either way), S4's
