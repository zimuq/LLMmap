## 4. S1 — selection, frozen before any training (`d037_select.py`, CPU)

1. **Rebuild** XY2 / XX2 (`d037_lib.accumulators()`, ≈ 2 min, 20.8 GB) and load the tensor (`d037_lib.tensor()`,
   sha asserted).
2. **Select** JG-mean = `jg_chain(XY2, XX2, ia, ib, 1.0)` and GC-mean = `gc_chain(S, 1.0)`, nested `k` = 1..8, ties
   to the lowest id. The chains, traces (objective, mean / min statistic or coverage, exact ties at the maximum)
   and `peak_k` are stored.
3. **The γ = 1 code-path checks that need the new chains** (Call 1). These are checked before anything is
   written:
   - `LLMmap/greedy_cover.verify_reduction(S, 8, "max")`: `greedy_cover(γ = 1)` equals the independent
     `mean_greedy`, and coverage is monotone;
   - JG-mean: at every step, the selected candidate's `CVaR₁(s)` equals the plain float64 mean of its per-pair
     statistic (|Δ| ≤ 1e-12, no NaN). The `joint_greedy` / `greedy_cvar` agreement is asserted inside `jg_chain`.
4. **Stop conditions** (the D's degeneracy stop, checked here as the D says): a non-unique `k` = 1 argmax (more
   than one exact tie at the maximum), or a constant objective trace, for either new chain. Either one means no
   commit; the stop is reported in R.
5. **Training order.** `d037_lib.train_order(S, ref)`:
   - a set equal to a D029 `k`-prefix of JG, **GC** or PAPER8 is trained in that arm's D029 order. D029 trained
     `cands[:k]`, i.e. chain order. The GC case extends `d031_lib.train_order` (Call 2);
   - otherwise, JG-shared queries in JG order, then ascending id (D024 Call 2).
6. **Identical-input `k`** per contrast (C1–C4, and each new arm vs PAPER8 / TOP-K[MEAN] / TOP-K[CVaR]). The
   differing `k` set each contrast's PARITY quantity for the mean-over-`k` secondary. If JG-mean's and GC-mean's
   sets coincide at some `k`, S2 asserts that they are bit-identical there.
7. **Descriptive rows (secondary (c), target-free):**
   - objective traces, and whether JG-mean's mean statistic falls as queries are added (D012's v1 finding);
   - overlaps at each `k` with JG, GC, TOP-K[MEAN], TOP-K[CVaR] and PAPER8;
   - within-set pair-profile correlation at `k` = 8: `d032_s0.within` on `d031_lib.similarity(Esf, "pearson")`,
     plus `"cos"`, for all grid arms and reference rows (D032's redundancy measure);
   - **D034 union:** the new chains' queries not already in D033's union or in the D035 / D036 chains.
8. **Commit and push** `results/D037/chains.json` (`frozen_before_training: true`) before S2 starts. S2 asserts
   this through `git log`.

## 5. S2 — training and scoring (`d037_train.py`, GPU node)

Only **JG-mean** and **GC-mean** are trained. JG, GC and PAPER8 (D029), and TOP-K[CVaR] / MMR-PP[CVaR] (D031)
and TOP-K[MEAN] (D032), are read verbatim.

- **Attention:**
  - D009 / D029 / D031 / D035 / D036 protocol: `d031_train.Ctx("v2", ("build", "val", "test"))`, `att_conf`,
    `run_one`;
  - seeds 0–4 × `k` = 1..8 × 2 arms = 80 runs, S_val for early stopping only;
  - the best checkpoint is reloaded on S_test and asserted against `run_one`'s accuracy and counts;
  - checkpoints go to `results/D037/models/` (gitignored).
- **Linear:**
  - D017 concat, 16 fits through `d035_train.pmap(d031_train._lin_worker)`, forked before the CUDA-initialising
    imports;
  - **32 BLAS threads**, D029's setting (the D; D036 Call 4): `OMP_NUM_THREADS=32 D031_WORKERS=2
    D031_THREADS=32`.
- **Exact-reproduction asserts** on identical-input `k` (every seed for attention; the linear fit):
  - a set equal to a JG or PAPER8 prefix: `d031_train.check_ident` against D029;
  - a set equal to a GC prefix: `cnt_total` / `cnt_model` equal D029's `counts_GC.npz` (`att|k|r|…`,
    `lin|k|…`), and logits equal `logits_GC.npz`. All of these are D029's own 32-thread outputs;
  - JG-mean and GC-mean with the same set at a `k`: their count arrays and logits are bit-identical;
  - a failed assert stops the job before anything is written, and goes to R as a stop.
- **Outputs:**
  - `run_counts.npz`, keys `<arm>|<k>|r<seed>|{cnt_total,cnt_model,cnt_pair,cnt_pair_all}`;
  - `linear_counts.npz`;
  - `logits_att.npz`, `logits_lin.npz` (gitignored);
  - `runs.json` with `chains_sha256`.
  - S_test counts are written, never printed.

**S3b** (`d037_analysis.py`, a separate short CPU job submitted only after the tail plot has been viewed):

- **Bootstrap:**
  - `d031_analysis.Boot("v2")`, shared by every arm. These are D031's v2 draws, the same as D032 / D035 / D036;
    the configs sha256 is asserted equal to D036's in S0;
  - the attention seed slot is `k` − 1; linear uses config draws only.
- **Primary, `k` = 8 (C1, C2).** For each endpoint E ∈ {E_all, E_tail (CVaR₀.₁ of all-pair two-logit
  accuracy)}, the attention Δ with its percentile interval, and the linear Δ point:

  | label | rule |
  |---|---|
  | BETTER | lo(Δ_all) > 0 and lo(Δ_tail) > 0, and linear Δ_all > 0 and Δ_tail > 0 (= `d031_analysis.label`) |
  | PARITY | both attention intervals ⊂ [−0.02, +0.02] |
  | WORSE | (hi(Δ_all) < 0 and linear Δ_all < 0) or (hi(Δ_tail) < 0 and linear Δ_tail < 0), the symmetric clause |
  | INCONCLUSIVE | otherwise, annotated "attention BETTER / WORSE, linear disagrees" when attention alone meets it |

  - The new function `label37` is checked against `d031_analysis.label` on every cell where the two rules agree
    by construction (every cell except the asymmetric-WORSE ones).
  - **C2's label is printed and written with the note "seen (D029 / D031)"** wherever it appears.
- **WORSE scan:** every ordered contrast among the four grid arms, TOP-K[CVaR], TOP-K[MEAN], MMR-PP[CVaR] and
  PAPER8 (56 ordered contrasts) at `k` = 8, under `label37`. Hits under D031's original asymmetric rule are listed
  too, marked as such.
- **Labelled secondaries:**
  - C3, C4 at `k` = 8 (`label37`);
  - the mean over `k` = 1..8 of Δ top-1 (attention) for C1–C4, with D036's verdict table (BETTER: lo > 0 and
    linear mean-`k` point > 0; WORSE: hi < 0 and linear point < 0; PARITY: the interval of the mean over the
    differing `k` ⊂ ±0.02; identical sets at every `k` → SAME CHAIN);
  - an independent-seed row for C1 and C2, where the second arm's seeds come from `default_rng(20261101)` (the
    D035 / D036 seed).
- **Descriptive:**
  - interaction (C1 − C3) at `k` = 8: the per-replicate difference of differences, E_all and E_tail, attention
    and linear, with an interval and no label;
  - (a) curves `k` = 1..8 for both readouts, and "queries to reach" JG's `k` = 4 / 8 E_all (smallest `k` with
    point E_all ≥ JG's, same readout; the D032 rule);
  - (b) hard sets at `k` = 8: H_all (57), stably-hard (26), N′ (161) vs the rest, levels and C1–C4 differences;
  - (c) from `chains.json`;
  - (d) the v1 side-by-side: `k` = 8 mean top-1 of the four v1 cells as published, read from
    `results/D012/metrics_by_gamma_k.json` (JG γ ∈ {0.1, 1}) and `results/D013/metrics_by_gamma_k.json` (GC
    γ ∈ {0.1, 1}). Different protocol era; never pooled with v2, no interval.
