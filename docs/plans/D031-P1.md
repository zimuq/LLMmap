## S0 — selection (one `gh` job, ≈ 30 min; no training, no S_val / S_test)

Everything is computed per view, from S_build objects only.

**S0.1 Assert §0.**

**S0.2 Helm's E (Call 1).**
- `E_raw` = the frozen raw tensor; `E_sf` = the frozen scale-free tensor. Both are (259 × P).
- **Recompute assert.** Use 3 queries (0, 193, 258) × 50 pairs (`default_rng(20261012).choice(P, 50)`).
  For each, compute `LLMmap.joint_statistic.energy_direct(A_q, B_q)` on the S_build cubes in float32.
  It must match the tensor:
  - raw: relative \|Δ\| ≤ 1e-5;
  - raw / within vs `E_sf`: absolute \|Δ\| ≤ 1e-6 (the D's assert).
- **Ordered vs unordered (the D's equivalence claim, asserted).**
  - Build `E_ord` (259 × n²): every ordered pair (i, i′), with the diagonal = 0. The V-statistic
    energy of a cloud with itself is exactly 0.
  - Assert, in float64:
    - `svd(E_ord)` singular values = √2 · those of `E_unord` (rel ≤ 1e-10);
    - \|U_ord^T U_unord\| = I on the first 20 directions (\|Δ\| ≤ 1e-8).
  - Only `E_unord` is used afterwards.

**S0.3 SVD, r̂, GMM (Helm steps 2–4; Calls 2–3).** For each E ∈ {raw, sf}:
- Run a plain float64 `numpy.linalg.svd(E, full_matrices=False)` with no centring. Fix each column
  of U so that its largest-magnitude entry is positive (sign convention only).
- **r̂** = argmax over s = 1…258 of σ_s / σ_{s+1}. Only s with σ_{s+1} > 1e-12 · σ_1 count; this
  guards against division by zero (Call 2).
- **GMM.** For each ℓ ≤ r̂:
  - fit `sklearn.mixture.GaussianMixture` to x_j = \|U_{jℓ}\| (259 values) with K = 1 and K = 2
    (`covariance_type="full"`, `n_init=10`, `random_state=0`, `max_iter=1000`, `tol=1e-6`), and keep
    the lower BIC;
  - **if K = 2:** the zero component is the one whose mean is nearer 0. Zero-set Ẑ_ℓ = queries whose
    MAP label is that component. ρ̂_ℓ = its mixture weight;
  - **if K = 1:** Ẑ_ℓ = ∅ and ρ̂_ℓ is not defined.
- **Estimated Orthogonal** = ∩_{ℓ ≤ r̂} Ẑ_ℓ. **Estimated Signal** = pool \ Orthogonal.
- **Diagnostics** (→ `chains.json["helm"]`):
  - full spectrum, every ratio, r̂ and the runner-up s;
  - per ℓ: both BICs, the means, variances and weights, ρ̂_ℓ, \|Ẑ_ℓ\|;
  - \|Signal\| and \|Orthogonal\|;
  - the same GMM on the **signed** U_{jℓ}, descriptive only (Call 3).

## S3 — budget section: MET at matched target budget (one `gh` job, GPU; after S1 is pushed)

**Per-sample kernel sums** (GPU; D030's data and code paths).
- For MET-Hamming and MET-e5, every target unit (model × 25 test configs), prompt *p*, sample *i*,
  and every reference model *m* and library *L* ∈ {Gen, All}, compute:
  - `kx[t, s, p, i, m, L]` = Σ over *m*'s 10 reference samples of prompt *p* of k(target sample,
    reference sample);
  - `ky[m, L, p]` = the sum over *m*'s reference off-diagonal pairs of prompt *p*.
- Hamming uses integer match counts, as D030's `met_hamming` but not summed over samples. e5 uses the
  RBF in float64 with the frozen σ.
- Shapes:
  - `kx`: 85 × 25 × 25 × 10 × 85 × 2 (≈ 0.7 GB int64 / float64 each);
  - `ky`: 85 × 2 × 25.

  Both go to `results/D031/budget_scores/` (gitignored).

**Score for a subsampled target** (P_d = drawn prompt set, n_s samples per prompt, I_{p} = drawn
sample indices):
- `score_m = 2 · Σ_{p∈P_d} Σ_{i∈I_p} kx[·, p, i, m] / (|P_d| · n_s · 10) − Σ_{p∈P_d} ky[m, p] / (|P_d| · 90)`.
- **Hamming in exact integers:** `|P_d|·n_s·90·L · score = 18 Σ kx − n_s Σ ky`. Ties are exact.
- The reference–reference term is restricted to the target's drawn prompts. That is the prompt-aware
  MMD with the target–target term dropped (it is constant across candidates).

**Draws** (Call 8).

| n | \|P_d\| × n_s | draws |
|---|---|---|
| 8 | 8 × 1 | 20 |
| 25 | 25 × 1 | 20 |
| 50 | 25 × 2 | 20 |
| 100 | 25 × 4 | 20 |
| 250 | 25 × 10 | 1 (deterministic, = D030) |

- Draw *d* fixes one prompt subset P_d, shared by every target unit: the prompts an attacker would
  send.
- Sample indices I_p are drawn independently per (target unit, prompt), without replacement from the
  10.
- All draws come from `rng("MET-BUDGET", view, f"n{n}")`.

**Code-path check first (stop on failure).** At n = 250, on every target unit and every candidate:
- Hamming: `18 Σkx − 10 Σky` == D030's integer score + 10·s_xx(target), exactly;
- e5: score − D030 score = s_xx / 2250, constant per target (\|Δ\| ≤ 1e-9);
- top-1 (including tie sets) identical to D030's on every target. The D's requirement.

**Counts** (`d030_s2_score.counts_from` unchanged; fractional tie credit, pairwise ties 0.5).
- Cells: {Hamming, e5} × {Gen, All} × view × n × draw.
- → `results/D031/budget_{met_hamming,met_e5}_{Gen,All}_{view}.npz` (committed), holding:
  - per n: the draw-mean `cnt_model`, `cnt_pair_all` and `tie` rate;
  - per draw: `cnt_total` and `cnt_model`.
- Per-draw pair arrays go to `budget_scores/` (gitignored).
- **MET\*** per view = the cell with the highest D030 S_test E_all at n = 250. It is read from
  `results/D030/analysis.json` (the D's rule; it favours MET). It is stated in R before any n < 250

- **Our curve:**

  - v1: D010 `k` = 1–8 + D025 GLOBAL `k` = 9–16 (attention + linear, as stored; D025 GLOBAL's first

## S4 — analysis (one CPU job; the single S_test read)

**Bootstrap** (per view; §0 draws, one draw set for every arm; Call 5 for the draw level).
- **E_all:** `M·cnt_total / (n ΣM)` per seed. The seeds are resampled with slot `k−1`, jointly across
  arms (D023 Call 1).
- **Pair accuracy:** `M·cnt_pair_all / (2 ΣM)`. **E_tail** = `cvar(·, 0.1)` over all P pairs, per
  draw.
- **Linear:** config bootstrap only.
- **Draw arms** (HELM-SIG, RANDOM; and budget MET at n < 250):
  - the arm's per-config counts = the mean over its draws, then E_all / E_tail as above (the D's
    rule);
  - Call 5 adds draw resampling to each bootstrap replicate (recommended).
- 95% percentile intervals. Resampling 5 seeds understates seed variance by 4/5 (disclosed, as
  D023 / D029).

**Order** (the D's S4):
1. **WORSE scan.**
   - Every X ∈ {HELM\*, TOP-K, MMR\*, RANDOM} × view, attention, `k` = 8:
     Δ_all = E_all(JG) − E_all(X), Δ_tail = E_tail(JG) − E_tail(X).
   - Also, descriptively, every non-starred variant.
   - Any hi < 0 → listed first in R.
2. **Labels** per X × view. The table is the D's:
   - WORSE > BETTER > PARITY > INCONCLUSIVE;
   - BETTER needs the linear point Δ_all > 0 and Δ_tail > 0;
   - PARITY needs both intervals ⊂ [−0.02, 0.02].

   The same table is also evaluated with linear as the label readout and reported (not a label).
3. **Draw-arm companions** (BReF style):
   - the between-draw SD of E_all and E_tail;
   - JG's percentile among the draws, linear (20 draws) and attention (10 draws, seed mean);
   - the mean over draws of per-draw E_tail (Call 5).
4. **Secondary (a)–(d)** + H_all mean (v2) + D019 model-set recall (v1):
   - (a) curves `k` = 1–8, all arms, both readouts, E_all and E_tail → `curves.png`. "Queries to
     reach" = the smallest `k` at which an arm's point E_all ≥ JG's at `k` = 4 and at `k` = 8.
   - (b) overlaps and D022 union flags (from S0).
   - (c) Helm diagnostics, and the ordering check: Signal vs Orthogonal vs uniform at `k` ∈ {2, 4, 8},
     linear, both E. Each is the draw-mean E_all and E_tail with a draw-level interval.
   - (d) **mandatory hard-tail plot:** sorted two-logit accuracy over all pairs, every arm at
     `k` = 8 (starred variants + JG + PAPER8), one panel per view plus a worst-10% zoom →
     `tail_{v2,v1}.png`.
5. **Budget section.**
   - MET\* and the label at n = k = 8: Δ = JG(`k` = 8, attention) − MET\*(n = 8), same label table.
     The linear sign clause uses JG linear `k` = 8.
   - All 4 MET cells × n × {E_all, E_tail} with intervals; the code-path check result.
   - The smallest n at which MET\* point E_all ≥ JG `k` = 8 E_all (or "none ≤ 250").
   - → `budget.png`: target-side completions (log x) vs E_all, MET cells vs our curve, per view.
6. → `results/D031/analysis.json`, `curves.png`, `tail_{v2,v1}.png`, `budget.png`.

## Calls

### Call 1 — E_raw is the frozen raw tensor, asserted; estimator disclosure

- The D says to "build E: raw squared energy from the frozen embeddings with `joint_statistic`".
- **What already exists.** D028 / D007 already built exactly this statistic for every cell, in the
  same `pair_worker` call that produced the frozen scale-free tensor:
  - `energy(A, B)` returns (raw, raw / within);
  - its sha is in `tensor_v2.json`.
- **TACC proposes** using that frozen array (I6: the same frozen tensor build) and asserting it on the
  D's 3 queries × 50 pairs, with `joint_statistic.energy_direct`:
  - raw, relative ≤ 1e-5;
  - raw / within vs the scale-free tensor, ≤ 1e-6 absolute.

  Rebuilding 259 × 3,570 cells would give the same numbers at ≈ 0.6 node-h.
- **Estimator.** The project's energy is the V-statistic (`cdist(...).mean()` including the zero
  diagonal). Helm et al. do not specify one; their experiments are temperature-0 with one response per
  query, so no estimator arises. Ours is over 75 configs per model (I3). Disclosed, not changed.

### Call 2 — the range of s in r̂ = argmax σ_s/σ_{s+1}

- Helm et al. give no range, and neither does the D.
- E is 259 × P with full row rank, so ratios exist up to s = 258. A noisy small-σ tail could in
  principle produce the maximum ratio deep in the spectrum, which would be a numerical artefact.
- **Options:**
  - (a) **Literal, recommended.** s = 1…258, with only a σ_{s+1} > 1e-12·σ_1 guard. If r̂ > 129
    (bottom half of the spectrum), R flags it as a probable tail artefact. It is reported, not patched
    (the D's degenerate-case rule).
  - (b) A cap fixed now, e.g. s ≤ 20.
- With (a), (b)'s r̂ is also reported as a diagnostic. The choice must be fixed before S0 runs; no
  spectrum has been computed.

### Call 3 — GMM details (Helm's text vs figure; small Signal sets)

- **\|U\| vs signed U.** Helm et al.'s text fits the signed loadings; their Figure 3 caption uses
  \|α̂\|. The D says \|U_{jℓ}\|. **TACC follows the D.**
  - For ℓ = 1 the two are identical: E ≥ 0 entrywise, so by Perron–Frobenius u₁ has one sign.
  - They differ only if r̂ > 1. The signed fit is reported as a diagnostic, not as a selectable
    variant.
- **Fixed settings:** `GaussianMixture(covariance_type="full", n_init=10, random_state=0,
  max_iter=1000, tol=1e-6)`, K ∈ {1, 2} by BIC, MAP assignment.
  - Helm's "ε from the GMM" is read as the MAP boundary.
  - "Component nearer 0" = the smaller \|mean\|.
- **If \|Signal\| < `k`:** that `k` is undefined for HELM-SIG (no sampling with replacement, no
  padding). If \|Signal\| < 8, HELM-SIG is ineligible for HELM\*, and R says so. The same rule
  applies to HELM-ORTH.
- **Signal for r̂ > 1.** Helm et al. do not define it clearly. The D's definition (complement of the
  intersection of zero-sets) is used.

### Call 4 — MMR similarity is uncentred cosine on non-negative profiles (disclosure)

- The D fixes sim = cosine between rows of the frozen scale-free tensor.
- Those rows are non-negative and share a strong common component (the first singular direction), so
  the uncentred cosine will be compressed near 1.
- The diversity term then varies less than rel′ ∈ [0, 1]. MMR may track TOP-K closely at λ ≥ 0.5,
  and λ = 0.3 gives it the most room.
- **TACC runs the D's definition** and reports the sim distribution plus MMR's overlap with TOP-K.
- A centred (Pearson) similarity would be a fourth variant. TACC does not add it unless the Review
  asks: no tuning beyond the pre-declared variants.

### Call 5 — the bootstrap for draw arms (needs a decision)

- The D fixes the arm's value as the mean over its draws, with the D023 config × seed bootstrap. As
  written, that interval treats the 20 (10) draws as fixed. The estimand "a random k-set" (or "a
  Signal-sampled k-set") then has draw-sampling error not in the interval.
- **Options:**
  - (a) **Recommended, conservative.** Each bootstrap replicate also resamples the draws with
    replacement:
    - `default_rng(20261012)`, shared across arms that have the same number of draws;
    - one draw-index vector per replicate for the 20-draw (linear) sets and one for the 10-draw
      (attention) sets.

    This only widens draw-arm intervals. JG and deterministic arms are unaffected.
  - (b) The D's literal scheme, no draw level.
- **E_tail of a draw arm:** the D's rule averages counts first, so E_tail = CVaR of the draw-mean pair
  accuracies. That favours draw arms: averaging lifts the tail. R reports it as the label value and
  also gives the mean over draws of per-draw CVaR.
- The same choice applies to the budget section's MET at n < 250.

### Call 6 — attention for every variant (disclosure)

- The D's cost line counts attention for the starred variants only. "All variants are trained and
  reported" is ambiguous about attention.
- Attention is cheap here: v2 ≈ 10 s per run (D029: JG, 50 runs + 10 linear fits, 16.1 min).
- TACC trains attention for all 4 HELM variants and all 3 MMR λ, after `variant_choice.json` is
  committed. The choice uses S_val linear only, so the extra runs cannot influence it. The labels use
  only the starred variants.

### Call 7 — training order, reproduction sources, and a citation slip (disclosure)

- The D cites "D023 Call 2 canonical order".
  - The canonical training order is D023 Call 3 / D024 Call 2: queries shared with JG in JG order,
    then ascending id. D023 Call 2 is the identical-`k` PARITY rule.
  - TACC applies D024 Call 2, extended to PAPER8 (a set equal to PAPER8's prefix is trained in
    PAPER8's order).
  - Logged as `TACC_NOTES` Issue 25. No effect on any number.
- v1 PAPER8 linear is not stored anywhere (D020 has no paper8 rows). It is fitted here and asserted
  against D017's stored mean top-1 (§S2).
- v1 JG linear all-pair arrays exist only at `k` = 8 (D030 Call 1). `k` = 1–7 are re-derived on D020's
  code path under the same `cnt_model` assert, and are used only in the curves.

### Call 8 — budget draws: what is shared, what is restricted (disclosure)

- **Prompt subsets are shared across targets within a draw.** One attacker sends one prompt set.
  Sample indices are independent per target unit and prompt (completions are i.i.d.).
- **The reference–reference term is restricted to the drawn prompts**, so the score is exactly the
  prompt-aware MMD of the subsampled target, up to its target-only term. At n = 250 the check proves
  this is D030's ranking.
- **Ties.** At n = 8 Hamming has one sample per prompt, and exact ties become likely. Credit is
  fractional (D030); tie rates are reported per cell and n.
- **The MET\* choice uses D030's S_test E_all at n = 250** (the D's rule, the only one available).
  It is stated in R as favouring MET.
- **Honesty note (the D's).** D030 read these S_test data at n = 250. The n < 250 values are new, and
  their rules are fixed here.

### Call 9 — no early start (disclosure)

- The D allows the generic arms to train while Helm's E is still being built.
- Every chain here comes from frozen tensors in minutes, and S0 builds them all in one job, so TACC
  does not use the allowance.
- Attention training cannot start before `variant_choice.json` anyway: `run_one` computes S_test
  logits, and the D bars any S_test number until both commits.
