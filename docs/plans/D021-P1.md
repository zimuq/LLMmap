## Uncertainty method — fixed now (D021 requires P to fix it before `ADD` touches the target)

**Leave-one-model-out (LOMO) jackknife, 37 folds.**

- Fold `m` drops every pair containing model `m` (36 pairs), leaving 630 of the
  666 pairs. Within each fold, every per-chain Spearman ρ (average ranks for
  ties) is recomputed on the 630 remaining pairs. The pooled statistic is the
  mean of the three per-chain ρ, and every Δρ is computed **within** the fold, so
  it is paired.
- `SE = sqrt((n−1)/n · Σ_m (T_(m) − T̄)²)` with `n = 37`. The 95% interval is
  `T̂ ± t_{0.975, 36} · SE`, where `t = 2.028` and `T̂` is the full-sample
  statistic. No bias correction. **Half-width = `t · SE`.**
- The same method is used for every interval in the D: primary, the
  non-ceiling subset, and the sensitivity variants.

**Why this and not a model-level bootstrap.**

1. **It handles the dyadic structure directly.** Every pair sharing the
   deleted model leaves together, which is the dependence D021 names.
2. **A model bootstrap is ill-defined here.** Resampling 37 models with
   replacement produces duplicate models. The "pair" between a model and its
   own copy has no target (D016 has no self-pairs), and dropping those pairs
   makes the effective pair set vary in a way unrelated to the question.
3. **It is deterministic**, so there's no seed and no second forking path.

Known limitation, stated in advance: a jackknife interval for a rank
correlation can be somewhat conservative. That works against GO (it widens
the non-inferiority bound), not for it.
