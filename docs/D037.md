## Why this D

- **JG combines two design choices:**
  - a **set-level joint statistic** (energy distance on the concatenated
    cloud);
  - a **tail criterion** (CVaR₀.₁ over pairs).
- **On v1 the full 2×2 grid exists:**
  - D012: JG γ = 1 loses to γ ≤ 0.25 almost everywhere, by ≈ 8 pp mean
    top-1;
  - D013: GreedyCover γ = 1 loses by the same amount;
  - D010: JG vs GreedyCover, joint vs MAX.
- **On v2 only the CVaR row exists:**
  - JG (D029);
  - GreedyCover γ = 0.1 (GC), D029 secondary and D031 reference row,
    descriptive only. JG − GC at `k` = 8: attention +1.1 pp
    [−1.3, +3.9], linear +1.9 pp [+0.7, +3.0].
- **The criterion's v2 evidence so far is from single-query rules only**
  (D032: TOP-K CVaR − mean +13.6 pp). JG's own γ dependence has never been
  measured on v2.
- **Design-side expectation (stated so it can be checked):**
  - the criterion contrasts come out BETTER;
  - joint vs MAX stays small.
  - Either way the grid is the honest attribution table for the paper,
    after D031 / D035 / D036 showed that JG's distinctive parts (joint
    combination, cloud energy) carry ≤ 2 pp on their own.

## What counts as an answer

**Endpoint: the D031 / D032 selection convention**, so that this grid sits
in one table with D032's Q1:
- S_test, `k` = 8, v2 85-way;
- **E_all** (top-1) and **E_tail** (CVaR₀.₁ of two-logit accuracy over all
  3,570 pairs);
- D023 hierarchical config × seed bootstrap with D031's v2 draws, 2,000
  replicates, shared by all arms.

| label | rule |
|---|---|
| **BETTER** | lo(Δ_all) > 0 **and** lo(Δ_tail) > 0, linear Δ agreeing in sign (point) on both |
| **PARITY** | both intervals ⊂ [−0.02, +0.02] |
| **WORSE** | hi(Δ_all) < 0 **or** hi(Δ_tail) < 0, **with the linear Δ on that endpoint agreeing in sign** (symmetric clause, DECISIONS 2026-11-02) |
| **INCONCLUSIVE** | otherwise; if attention alone meets BETTER or WORSE, R reports "attention X, linear disagrees" |

- **WORSE scan:** every ordered contrast among the four grid arms and the
  reference rows. Hits under D031's original (asymmetric) WORSE rule are
  listed too, marked as such.
- No multiplicity correction (D017–D036 convention); every cell is
  reported.

**Labelled secondary (D035 / D036 convention, for the fingerprint-ablation
table):** for C1–C4, the mean over `k` = 1..8 of Δ mean top-1 (attention),
with D036's verdict table. The independent-seed row is reported for C1 and
C2.
