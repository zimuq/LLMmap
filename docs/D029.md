## D — The question

> **On corpus v2, with every method choice frozen from v1, does
> JointGreedy-CVaR beat LLMmap's own 8 queries on the hard pairs without
> breaking the all-model guardrail? And for the hardest families, is the
> limit LLMmap's queries, our pool, or missing ammunition the pool cannot
> supply?**

### Arms (chains frozen and committed before any training)

| arm | candidates | selection | `k` |
|---|---|---|---|
| **PAPER8** | the paper's 8 queries | the paper's order | 1–8 |
| **JG** | 259 pool | JointGreedy-CVaR, energy scale-free, **γ = 0.1** (D010/D012; `LLMmap.joint_greedy`), v2 S_build | nested 1–16 |
| **JG+ML** | 259 + 16 multilingual (ids 281–296) | the same, on S_build | nested 1–16 |
| **GC** *(secondary)* | 259 pool | GreedyCover (MAX coverage, I4), γ = 0.1 (D013), on `S_energy_sf_tok200_v2` | 1–8 |

**Nothing is tuned:** γ, the statistic, the readouts and `k` = 8 are v1's.
D025's lesson holds: **global chains only, no pair or family specialists.**

### Readouts

- **Attention** (LLMmap's network, D009 protocol, seeds 0–4, early
  stopping on S_val).
- **Linear** (D017 concat, C = 1.0, deterministic).
- **Primary label readout: attention** (design-side default). It is
  LLMmap's own network, and the v2 hard set was defined with it. The human
  may switch this to linear at P review, before any training. Linear is
  always reported and must agree in sign for CONFIRMED.
- **Ammunition tests (P1–P3) use linear**, the stronger readout. A pair
  that fails under linear is not just classifier-limited (D025 convention).
  Attention is reported alongside.

## What counts as an answer

**Endpoints** (S_test, read once; corpus v2):
- **E_hard:** mean two-logit accuracy over **H_all** (57 pairs; each pair
  from both members' S_test traces).
- **E_all:** 85-way mean top-1 over all 85 models.
- **Contrast:** Δ = JG − PAPER8 at `k` = 8.
- **Intervals:**
  - attention: D023's hierarchical config × seed bootstrap (paired, 2,000
    draws, seeds resampled jointly);
  - linear: paired config bootstrap (`d008_lib.boot_draws(25, 2000,
    seed=20261005)`);
  - one draw set shared by all arms.

**Primary label (attention, `k` = 8):**

| label | rule (checked in this order) |
|---|---|
| **GUARDRAIL BREACH** *(headline)* | lo(Δ_all) ≤ −0.02, **whatever** Δ_hard shows |
| **CONFIRMED** | lo(Δ_hard) > 0 **and** lo(Δ_all) > −0.02 **and** linear Δ_hard > 0 |
| **NOT CONFIRMED** | hi(Δ_hard) < +0.02 |
| **INCONCLUSIVE** | otherwise |

**Guardrail-headline rule (human, 2026-10-03).** If any arm's E_all or
E_hard gain coincides with a guardrail failure (lo(Δ_all) ≤ −0.02) **at any
`k` or under either readout**:
- it goes in R's first lines and the Review's "For you";
- it is never left in a secondary table;
- this holds even when the primary label is something else.

**Secondary (descriptive unless stated):**
- (a) E_hard by stratum:
  - H_N, plus F_N family 85-way recall (D7 continuity);
  - H_X, plus M_X recall;
  - only the stably-hard pairs;
  - **without the 5 `mode_mixed` pairs** (D028 A1);
  - **fresh-only** (pairs whose two members are both new models).
- (b) E_all by block: new 48 (fresh test) vs v1 37 (test read before);
  Δ_all and its CI per block.
- (c) Curves `k` = 1–8 (and 12, 16 for JG / JG+ML), both readouts, all
  arms.
- (d) GC vs PAPER8 and GC vs JG: does v1's "coverage alone is the weak link"
  replicate (sign only)?
- (e) Per-pair table for H_all: PAPER8 / JG / JG+ML at `k` = 8 and 16, both
  readouts.
- (f) Confusion summary for the tiny-aya family: within-family vs
  out-of-family errors, PAPER8 vs JG (from saved test logits).

### Ammunition predictions — formalised from D028 (recorded 2026-10-03 / 05, before any v2 chain)

All three use **linear, S_test, mean two-way accuracy over the named pairs,
paired config bootstrap**.

- **P1 — tiny-aya is ammunition-limited.**
  - T1 = the 6 tiny-aya pairs.
  - a = acc(JG, `k` = 16); b = acc(JG+ML, 16) − a.
  - **SUPPORTED:** hi(a) < 0.90 **and** b ≥ +0.05 with lo(b) > 0.
  - **POOL-LIMITED ONLY:** hi(a) < 0.90, b not supported. The pool fails,
    and the multilingual probes did not fix it or were not selected. If
    JG+ML selects no ML probe by `k` = 16, then b ≡ 0, and R says so.
  - **REJECTED:** a ≥ 0.90 (point). The pool has the ammunition.
  - **INCONCLUSIVE:** otherwise.
  - **Descriptive companion** (no label): JG `k` = 8 plus all 16 ML probes
    appended. This shows whether the probes carry signal regardless of
    selection.
- **P2 — Ministral-3 is not ammunition-limited.**
  - T2 = the 3 Ministral-3 size pairs.
  - **SUPPORTED:** acc(JG, 16) ≥ 0.90 (point).
  - **REJECTED:** hi < 0.90.
  - **INCONCLUSIVE:** otherwise.
- **P3 — the top-coverage Qwen pairs are limited by LLMmap's queries, not
  the pool.**
  - T3 = every Qwen pair in H_N **except** Qwen3.5-4B↔9B (bottom coverage,
    P1-type) and Qwen2.5-7B↔7B-1M (context twin). That leaves 11 pairs:
    - Qwen2-1.5B↔Qwen2.5-0.5B;
    - Qwen2.5-3B↔Qwen2.5-7B;
    - the 9 Qwen3 pairs in H_N.
  - *Correction (design-side, 2026-10-05, `TACC_NOTES` Issue 23): the rule
    gives **10** pairs (8 Qwen3 pairs, not 9). The rule governs; T3 = 10.*
  - **SUPPORTED:** acc(JG, `k` = 8) ≥ 0.90 (point).
  - **REJECTED:** hi < 0.90.
  - **INCONCLUSIVE:** otherwise.
- **Design-side lean:** P1 likely, P2 coin-flip, P3 likely.
