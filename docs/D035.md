## Why this D

- D024 (v1, 37 models, 666 pairs) found two things under JG:
  - **multi-config reference data is the big effect:** SINGLE 0.659 → best
    centroid 0.791 (mean top-1 over `k` = 1..8);
  - **keeping the distribution adds a smaller, consistent edge:** CLOUD −
    raw centroid +1.5 pp [+0.2, +2.7], larger on hard models; the tail was
    unresolved.
- Neither result has been re-tested on v2 (85 models, 3,570 pairs, 57 hard
  pairs, many more near-relatives). v2 is where the main-method claims now
  rest.
- **D024's lesson applies here from the start.** Its pre-registered verdict
  was against a median-normalised centroid that turned out to be a strawman
  (−8 pp), so the +1.5 pp had to come from a post-hoc amendment. Here both
  centroid variants are pre-registered, and the verdict is against the
  stronger one, chosen on S_val.

## D — The question

> **On corpus v2, with the selection algorithm held fixed (JointGreedy,
> greedy CVaR₀.₁ over all 3,570 pairs of a set-level statistic, nested
> `k` = 1..8), does the chain selected on point clouds (the existing D029 JG
> chain) train to higher accuracy than chains selected on (i) the per-model
> centroid of the same clouds and (ii) a single reference config per
> model?**

### Arms

| arm | a model `v`'s fingerprint for query `q` | set-level statistic between `v`, `v'` | status |
|---|---|---|---|
| **CLOUD** | the 75 S_build response embeddings | scale-free joint energy distance (D010 / D029) | **D029's v2 JG chain and counts, reused verbatim** |
| **CENTROID-raw** | the mean of those 75 embeddings | `sqrt(Σ_q ‖μ_vq − μ_v'q‖²)`, un-normalised | new |
| **CENTROID-norm** | same mean | the same, with each `d²_q` divided by its median over the 3,570 pairs (D024's primary definition) | new |
| **SINGLE** | one embedding from one reference config per model (D024's tier rule, below) | the same distance on single points, **in the CENTROID variant chosen on S_val** | new |

- **CENTROID\*** = whichever of CENTROID-raw / CENTROID-norm has the higher
  S_val attention mean top-1 over `k` = 1..8. The S_val choice is made and
  committed before any S_test read (D031 strongest-variant rule).
- **SINGLE reference config:** D024's rule verbatim. Per model, in S_build,
  take the first match in this order:
  1. no system prompt, no RAG, no CoT;
  2. system prompt exactly "You are a helpful assistant.", no RAG, no CoT;
  3. no RAG, no CoT.

  Within the chosen tier, take the **greedy** config (D024 Call 1 (b):
  greedy = temperature 0). If the tier has no greedy config, take the lowest
  temperature, then the lowest config index. S0 reports the tier and config
  assigned to each model.
- **SINGLE-field** (D024's literal "lowest temperature field" reading) is
  selection only: chain and overlap with SINGLE. **Not trained.**
- **Selection** for every new arm: greedy, maximising CVaR₀.₁ over the
  3,570 pairs (`m` = 357, the `cvar()` definition), nested `k` = 1..8, ties
  to the lowest query id.
  - Same wrapper as `d024_lib.py`, with only the pair set and the
    statistic changed.
  - **Code-path check:** the wrapper with the CLOUD statistic must reproduce
    D029's v2 JG chain exactly, with per-step objective diff 0.

### What each comparison isolates

- **CLOUD − CENTROID\*** isolates the **within-model spread**. Both use all 75
  configs; only the spread is dropped. This is the claim "the full
  distribution matters".
- **CENTROID\* − SINGLE** isolates **multi-config reference data**. It is the
  selection-level analogue of AdaptPrint's Gen → All jump and of D030's MET /
  ZeroPrint Gen → All recovery.
- **Literature mapping (for the writeup):**
  - CENTROID ≈ DKPS-style mean response embeddings (arXiv 2410.01106),
    averaged over configs rather than over samples.
  - SINGLE ≈ AdaptPrint-Gen references (arXiv 2608.22213) and Helm et
    al. 2026's T = 0 point mass (arXiv 2605.07878).
  - The "single config, many samples" cell (MET / ZeroPrint native) cannot
    be built from the frozen corpus. D030 covers it with its own
    generations.

## What counts as an answer

**Primary endpoint (as D024, for direct comparability).**
- **Quantity:** the mean over `k` = 1..8 of Δ mean top-1 (85-way), attention
  readout.
- **Bootstrap:** D023's hierarchical config × seed scheme with D031's v2
  draws, 2,000 replicates; one set of draws shared by all arms.
- **Sensitivity row:** independent seeds.
- δ = 0.02.

| comparison | role |
|---|---|
| **(P1) CLOUD − CENTROID\*** | the full-distribution claim |
| **(P2) CENTROID\* − SINGLE** | the multi-config-reference claim |
| CLOUD − SINGLE | reported, no separate verdict |
| CLOUD − (the other CENTROID variant) | reported, no verdict |

| outcome (each of P1, P2) | criterion |
|---|---|
| **BETTER** | lower bound > 0 (mean over `k` = 1..8) |
| **PARITY** | interval ⊂ [−δ, +δ] (mean over the *differing* `k`) |
| **WORSE** | upper bound < 0 |
| **INCONCLUSIVE** | otherwise |

- **Label readout:** attention, with linear agreeing in sign for BETTER (the
  D029–D033 convention).
- P1 and P2 are separate questions. Do not merge them into a single
  "fingerprint matters" verdict (D024 Review).
- **D024 comparison:** for each of P1 / P2, report the v1 value from D024
  next to v2. Agreement or disagreement is described, not labelled.

**Secondary (labelled, current convention, `k` = 8):** E_all and all-pair
E_tail (CVaR₀.₁ two-logit accuracy) for P1 and P2, with labels as D031.
The WORSE scan runs over every trained-arm contrast at `k` = 8.

**Secondary (descriptive):**
- (a) **Linear readouts** (as in D031): the same quantities.
- (b) **Hard cases at `k` = 8:**
  - D029's frozen v2 hard-pair set (57 pairs) and its stably-hard stratum;
  - D027's N′ near-relative pairs vs the rest;
  - the mandatory hard-tail plot (I1), all arms.
- (c) **Chains:**
  - overlaps among arms and with PAPER8;
  - the SINGLE / SINGLE-field overlap;
  - each chain's objective trace.
- (d) **SINGLE collisions:** count the exact-zero cells (byte-identical
  greedy responses) per pair and per query. List the pairs with the most
  collisions; v1's was Phi-3-medium 128k ↔ 4k at 46 queries.
